# Logo

Letakkan logo resmi Universitas Hasanuddin di folder ini dengan nama **`logo-unhas.png`** (disarankan PNG persegi/transparan, ≥ 256×256 px;
`logo-unhas.jpg` atau `logo-unhas.svg` juga dikenali). Logo tampil di halaman masuk, bilah samping, halaman verifikasi surat, serta
kop surat/laporan PDF (PNG/JPG). Tanpa berkas ini aplikasi menampilkan ikon netral.
