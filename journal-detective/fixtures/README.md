# Dataset demonstrasi — SELURUHNYA FIKTIF

Semua jurnal, penerbit, ISSN (rentang 9900-xxxx, sengaja fiktif), domain (`.example`, TLD yang dicadangkan RFC 2606)
dan nama orang pada folder ini adalah **fiktif** dan dibuat hanya untuk demonstrasi/pengujian.
Berkas ini **bukan** data Scopus, SCImago, Beall, atau Retraction Watch yang asli.

Untuk produksi, impor berkas resmi yang diperoleh secara sah melalui menu **Sumber Rujukan**
dan nonaktifkan dataset demonstrasi.
